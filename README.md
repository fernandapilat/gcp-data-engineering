# GCP Data Engineering Portfolio

This repository documents my technical projects and studies focused on the **Google Cloud Platform (GCP)** ecosystem. The content is divided into two main pillars: Cloud Infrastructure Foundations and BigQuery Data Warehousing.

The goal is to demonstrate practical skills in environment setup, service management, and advanced analytical SQL.

---

## Repository Structure

The portfolio is organized into specialized modules:

| Module | Description | Key Technologies |
| :--- | :--- | :--- |
| [**Cloud Infrastructure**](./cloud/) | Serverless compute, security, and API management. | App Engine, Cloud Run, IAM, Cloud Endpoints |
| [**BigQuery & Analytics**](./big-query/) | Data warehousing, query optimization, and SQL logic. | BigQuery, SQL, DML/DDL, Partitioning |

---

## Technical Competencies

### Cloud Operations
* **Serverless Compute:** Deployment of services using App Engine and Cloud Run.
* **API Governance:** Protection and management of APIs with Cloud Endpoints and ESP.
* **Identity & Access:** Management of IAM Roles, Service Accounts, and API Keys.
* **Infrastructure:** Automation via Gcloud CLI and YAML configuration.

### Data Engineering (BigQuery)
* **Data Manipulation:** Advanced use of Subqueries, Joins, and UNNEST for complex data structures.
* **Temporal Analysis:** Implementation of dynamic calendars and time-series extraction.
* **Logic & Performance:** Complex conditional logic (CASE WHEN) and query optimization patterns.
* **Data Cleaning:** String manipulation and data formatting for analytical readiness.

---

## Project Highlights

* **Secure API Gateway:** Implementation of a management layer for Python APIs.
* **Dynamic Calendar Engine:** SQL-based solution for generating continuous time-series data.
* **Serverless Microservices:** Deployment of containerized applications using Docker and Cloud Run.
