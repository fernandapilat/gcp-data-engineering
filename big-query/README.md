# BigQuery Data Engineering & Analytics Specialization

This repository contains study notes, advanced queries, and project developments from the Google BigQuery Specialization. The training establishes a solid foundation in cloud data warehousing, covering everything from environment setup to advanced data manipulation and query optimization.

---

## Curriculum Overview

### Phase 1: Foundation and Cloud Architecture
| Course | Focus Area | Key Skills |
| :--- | :--- | :--- |
| **1. Navigating the Cloud** | Foundations of SQL in the Cloud | Subqueries, Grouped filtering (HAVING), Arrays, Structs, and UNNEST for data flattening. |

### Phase 2: Data Cleaning and Logic Mastery
| Course | Focus Area | Key Skills |
| :--- | :--- | :--- |
| **2. Mastering Strings and Date** | Data Preparation | String manipulation (formatting/regex), Temporal analysis (Date, Time, Timestamp), and Time-series extraction. |
| **3. Mastering Logical and Numerical Functions** | Advanced Reasoning | Complex mathematical operations, conditional expressions (CASE WHEN), and efficient data filtering. |

### Phase 3: Advanced Manipulation and Performance
| Course | Focus Area | Key Skills |
| :--- | :--- | :--- |
| **4. Data Manipulation** | Big Data Management | Import/Export, dataset optimization, and real-time analysis of large volumes of data. |
| **5. Advanced Queries** | Automation and Control | Stored Procedures, User-Defined Functions (UDFs), IF/LOOP control structures, and Query Optimization. |

## Technical Skills and Tools

| Category | Description |
| :--- | :--- |
| **Language** | Standard SQL (ANSI 2011) |
| **Platform** | Google Cloud Platform (GCP) / BigQuery |
| **Architecture** | Columnar Storage, Serverless Compute, Slot Management |
| **Optimization** | Partitioning, Clustering, Predicate Pushdown, Column Pruning |
| **Advanced Features** | Window Functions, Common Table Expressions (CTEs), Recursive Queries, Nested Data |
